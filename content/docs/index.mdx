# Blazing Agents

Blazing Agents runs the production infrastructure for your AI agents, so you can ship agent features without building a backend for them.

You write the agent logic: instructions, the model it uses, and the tools it can call. Blazing Agents runs everything around it. Conversations are stored, files survive between sessions, background tasks keep running after your request returns, and every turn's token usage is tracked. You call it from your backend with an SDK or plain HTTP. Read [why teams use Blazing Agents](/why) for the longer case.

## See it work [#see-it-work]

Save a model provider, create an agent that uses it, and stream its first reply. Set `BLAZING_AGENTS_API_KEY` from your [dashboard](https://www.blazingagents.com/app/keys) and `OPENAI_API_KEY` from OpenAI, then run:

```typescript tab="TypeScript"
import { BlazingAgents, type UIMessage } from "@blazingagents/sdk";

const client = new BlazingAgents({
  apiKey: process.env.BLAZING_AGENTS_API_KEY!,
});

const provider = await client.providers.create({
  name: "OpenAI",
  providerType: "openai",
  baseUrl: null,
  apiKey: process.env.OPENAI_API_KEY!,
});

const agent = await client.agents.create({
  name: "Support agent",
  instructions: "Answer clearly and briefly.",
  providerId: provider.id,
  model: "gpt-4.1",
});

const message = {
  id: crypto.randomUUID(),
  role: "user",
  parts: [{ type: "text", text: "How can you help?" }],
} satisfies UIMessage;

const result = await client.chat({ agentId: agent.id, message });
console.log(`Session: ${await result.sessionId}`);

for await (const chunk of result.toStream()) {
  process.stdout.write(chunk);
}
```

```python tab="Python"
import os
import sys
import uuid

from blazing_agents import BlazingAgents

with BlazingAgents() as client:
    provider = client.providers.create(
        name="OpenAI",
        provider_type="openai",
        api_key=os.environ["OPENAI_API_KEY"],
    )

    agent = client.agents.create(
        name="Support agent",
        instructions="Answer clearly and briefly.",
        provider_id=provider.id,
        model="gpt-4.1",
    )

    message = {
        "id": str(uuid.uuid4()),
        "role": "user",
        "parts": [{"type": "text", "text": "How can you help?"}],
    }

    with client.chat(agent_id=agent.id, message=message) as stream:
        print(f"Session: {stream.session_id}")
        for chunk in stream:
            sys.stdout.buffer.write(chunk)
```

You create the provider and agent once and reuse them. Each chat call returns a session ID right away; pass it to the next call to continue the same conversation. The stream is standard AI SDK server-sent events, so in a route handler you can return `result.toResponse()` and hand it straight to a `useChat` frontend. Keep your API key on your backend. [Run your first agent](/getting-started/quickstart) walks through each step.

| Interface | Use it when |
| --- | --- |

| [Python SDK](/sdk/python) | Your backend runs Python, sync or async. |
| [REST API](/api-reference/rest-api) | You work in another language or want direct HTTP control. |
| [CLI](/cli) | You want to chat with agents or script one-off runs from a terminal. |
