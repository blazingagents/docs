# Agents

An agent is the part of Blazing Agents you configure. You choose its model, write its instructions, and decide what it can use: files, skills, memory, and tools. Your app then calls it by ID for chat, one-off answers, or background work.

If you have not built one yet, start with [Run your first agent](/getting-started/quickstart).

## How the pieces fit [#how-the-pieces-fit]

Each call to an agent is a turn. The first turn in a session saves the agent's configuration for later turns in that session. A task run saves it when queued. A one-off turn uses the agent's current configuration. During the turn the agent can load a skill, read or save memory, work with files in its workspace, and call tools. The answer streams back as text or arrives as structured JSON.

Turns that belong to a conversation live in a [session](/platform/sessions-and-turns). Scheduled and background turns run as [tasks](/automation/tasks).
