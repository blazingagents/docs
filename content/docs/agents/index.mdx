# Agents

An Agent combines model configuration, instructions, durable context, and
approved capabilities into a reusable execution unit. Configure an Agent once,
then invoke it through a [Session](/platform/sessions-and-turns), stateless
generation, or [Automation](/automation).

The Agent section explains the product model: what each resource does, how the
resources relate, and which lifecycle or security boundaries matter. For exact
language methods and types, follow the links to the [TypeScript SDK](/sdk/typescript)
or [Python SDK](/sdk/python).

## How the pieces fit [#how-the-pieces-fit]

Every Agent has a current configuration and Workspace. A Turn resolves that
configuration, invokes the selected Provider and model, and may load Skills,
read or change Memory, use built-in or MCP Tools, and produce streamed or
structured output. Stateful Turns belong to Sessions; scheduled and background
execution belongs to Automation.

## Choose an interface [#choose-an-interface]

- Use the [CLI](/cli) to learn BA interactively, run Agents, and automate shell workflows.
- Use the [TypeScript SDK](/sdk/typescript) or [Python SDK](/sdk/python) from application code.
- Use the [TypeScript Agents object](/sdk/typescript/agents) or [Python Agents object](/sdk/python/agents) for exact Agent operations.
- Use the [API reference](/api-reference) for HTTP operations and wire contracts.
