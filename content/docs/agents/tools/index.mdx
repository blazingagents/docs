# Tools

Tools let an Agent act instead of only generating output. Blazing Agents can
expose platform-provided Tool groups, discover Tools from attached MCP servers,
and pause sensitive calls until a human makes a durable decision.

## Tools are not Skills [#tools-are-not-skills]

A Tool is a callable operation. A [Skill](/agents/skills) is progressively
loaded instruction and resource content that teaches an Agent how to perform a
kind of work. A Skill can direct an Agent to use Tools, but it does not itself
grant a Tool capability.

## Tool activity [#tool-activity]

Successful Session Turns retain Tool calls and results as message parts. A
proposed sensitive call may instead create a pending approval and resume in a
new continuation Turn after the decision. See [Sessions and Turns](/platform/sessions-and-turns)
for transcript and execution behavior.
