# Tools

Tools let your agent do things instead of only writing text. Turn on the tools Blazing Agents provides, connect your own services through MCP, and decide which calls need someone's approval before they run.

## Tools and skills [#tools-and-skills]

A tool is an action the agent can call. A [skill](/agents/skills) is a set of instructions and files that teaches the agent how to do a kind of work. A skill can tell the agent to use a tool, but it cannot give the agent a tool it does not already have.

## See what the agent did [#see-what-the-agent-did]

When a chat turn succeeds, each tool call and its result is saved in the session as part of the assistant's message, so you can show it in your UI or check it later. When a call needs approval, the agent pauses and continues in a new turn after the decision. See [sessions and turns](/platform/sessions-and-turns).
