# Structured output

Get data your code can use directly instead of prose you have to parse. You give the agent a JSON Schema, and the model's answer is held to that shape while it is generated. Use it for extraction, classification, routing, and any other result with a known structure.

## Generate an object [#generate-an-object]

This example triages a support message into a category, an urgency flag, and a summary:

```typescript tab="TypeScript"
import { z } from "zod";

const Triage = z.object({
  category: z.enum(["billing", "technical", "other"]),
  urgent: z.boolean(),
  summary: z.string(),
});

const result = await client.object({
  agentId,
  prompt: "Triage: I was charged twice and need a refund today.",
  schema: {
    type: "object",
    properties: {
      category: { enum: ["billing", "technical", "other"] },
      urgent: { type: "boolean" },
      summary: { type: "string" },
    },
    required: ["category", "urgent", "summary"],
    additionalProperties: false,
  },
});

const triage = Triage.parse(await result.object);
console.log(triage.category, triage.urgent);
```

```python tab="Python"
from typing import Literal

from pydantic import BaseModel


class Triage(BaseModel):
    category: Literal["billing", "technical", "other"]
    urgent: bool
    summary: str


triage = client.object(
    agent_id=agent_id,
    prompt="Triage: I was charged twice and need a refund today.",
    output_type=Triage,
)
print(triage.category, triage.urgent)
```

```rust tab="Rust"
use blazing_agents::generation::ObjectSchema;
use schemars::JsonSchema;
use serde::Deserialize;

#[derive(Debug, Deserialize, JsonSchema)]
#[serde(rename_all = "lowercase")]
enum Category {
    Billing,
    Technical,
    Other,
}

#[derive(Deserialize, JsonSchema)]
struct Triage {
    category: Category,
    urgent: bool,
    summary: String,
}

let triage: Triage = client
    .object(
        agent_id,
        "Triage: I was charged twice and need a refund today.",
        ObjectSchema::<Triage>::derive(),
    )
    .await?;
println!("{:?} {}", triage.category, triage.urgent);
```

In TypeScript, `result.object` resolves to `unknown`, so validate it with your own schema, here Zod, before you use it. In Python, pass a Pydantic model as `output_type`: the SDK sends its JSON Schema and returns a validated instance. In Rust, one struct deriving `Deserialize` and `JsonSchema` does both jobs: `ObjectSchema::derive()` sends its schema and the call returns the decoded value. You can also pass a raw schema as `json_schema` (`ObjectSchema::<serde_json::Value>::from_json_schema(schema)` in Rust) to get plain JSON back.

## Show progress while it streams [#show-progress-while-it-streams]

Long objects can take a while. You can show progress as the JSON arrives, then use only the final value:

```typescript tab="TypeScript"
for await (const partial of result.partialObjectStream) {
  console.log("so far:", partial);
}
const triage = Triage.parse(await result.object);
```

```python tab="Python"
with client.object_stream(
    agent_id=agent_id,
    prompt="Triage: I was charged twice and need a refund today.",
    output_type=Triage,
) as stream:
    for json_text in stream:
        print(json_text, end="")
    triage = stream.get_final_object()
```

```rust tab="Rust"
use blazing_agents::generation::ObjectSchema;
use futures_util::TryStreamExt;
use schemars::JsonSchema;
use serde::Deserialize;

#[derive(Debug, Deserialize, JsonSchema)]
#[serde(rename_all = "lowercase")]
enum Category {
    Billing,
    Technical,
    Other,
}

#[derive(Deserialize, JsonSchema)]
struct Triage {
    category: Category,
    urgent: bool,
    summary: String,
}

let mut stream = client
    .object_stream::<Triage>(
        agent_id,
        "Triage: I was charged twice and need a refund today.",
        ObjectSchema::<Triage>::derive(),
    )
    .await?;
while let Some(json_text) = stream.try_next().await? {
    print!("{json_text}");
}
let triage = stream.final_object().await?;
```

TypeScript gives you partial objects parsed from the JSON so far. Python and Rust give you the raw JSON text. Either way, a partial value can miss required fields or end mid-string, so use it for display only and never as a fallback result.

## Write a schema that works [#write-a-schema-that-works]

The schema must be a JSON Schema object with at least `type` or `properties`. An empty schema, an invalid one, or one that uses features the model cannot enforce is rejected with [`validation_failed`](/api-reference/protocols/errors#validation_failed) before anything runs. Keep schemas small and specific: list `required` fields, use `enum` for fixed choices, and set `additionalProperties: false`. See [objects and schemas](/api-reference/protocols/objects-and-schemas) for the supported features.

## What to expect [#what-to-expect]

- **No history.** Structured output creates no session and saves no transcript, so the agent cannot publish [artifacts](/agents/artifacts) during it. Everything else about the agent applies, including its tools.
- **Usage is recorded** whether the request succeeds, fails, or is stopped.
- **Invalid final JSON fails.** If the answer does not parse, `result.object` rejects with `stream_error`, Python raises a stream error, and Rust returns an object error. A dropped connection or abort also ends without a final object.
- **Saved prompts.** Pass `promptId` with its `variables` instead of `prompt` to use a saved [prompt](/agents/prompts). Each call uses the agent's current configuration.
