# Generation and streaming

Get text from your agent as it is written. Use `client.chat()` for a conversation: Blazing Agents saves the history in a session, and each answer streams in the AI SDK UI message format your frontend can render directly. Use `client.completion()` for one-off text, such as a summary or a rewrite, where you want no history at all.

## Stream one-off text [#stream-one-off-text]

```typescript tab="TypeScript"
const result = await client.completion({
  agentId,
  prompt: "Write a two-sentence release note for passkey login.",
});

for await (const delta of result.textStream) {
  process.stdout.write(delta);
}
process.stdout.write("\n");
```

```python tab="Python"
with client.completion_stream(
    agent_id=agent_id,
    prompt="Write a two-sentence release note for passkey login.",
) as stream:
    for delta in stream:
        print(delta, end="", flush=True)
print()
```

```rust tab="Rust"
use futures_util::TryStreamExt;
use std::io::Write;

let mut stream = client
    .completion_stream(
        agent_id,
        "Write a two-sentence release note for passkey login.",
    )
    .await?;

let mut stdout = std::io::stdout();
while let Some(delta) = stream.try_next().await? {
    stdout.write_all(delta.as_bytes())?;
}
stdout.write_all(b"\n")?;
```

```go tab="Go"
stream, err := client.Generation.CompletionStream(ctx, agentID,
	ba.Text("Write a two-sentence release note for passkey login."), ba.GenerateParams{})
if err != nil {
	return err
}
defer stream.Close()

for delta, err := range stream.Deltas() {
	if err != nil {
		return err
	}
	fmt.Print(delta)
}
fmt.Println()
return nil
```

If you only need the finished text, skip the loop: `await result.text` in TypeScript, `client.completion(...)` in Python and Rust, or `client.Generation.Completion(...)` in Go, which return a string.

## Choose chat or completion [#choose-chat-or-completion]

| | `client.chat()` | `client.completion()` |
| --- | --- | --- |
| Input | One or more user messages in AI SDK `UIMessage` shape, or a saved [prompt](/agents/prompts) | Plain text, or a saved prompt |
| History | Starts a session, or continues one when you pass its ID | None |
| Output | An AI SDK UI message stream, plus the session ID | Plain text deltas |
| Good for | Chat interfaces and multi-step conversations | Summaries, rewrites, and other standalone text |

Both run the same agent with the same tools, skills, MCP connections, memory, and workspace, and both record usage. To get JSON in a fixed shape instead of text, use [structured output](/agents/output/structured-output).

## Relay chat to your frontend [#relay-chat-to-your-frontend]

Your backend holds the API key, signs the user in, and passes the stream through unchanged. It calls the user's own agent through a client scoped to that user, so Blazing Agents refuses another user's session. Here `accounts` stands in for your sign-in and storage: it maps a session token to the user and the agent you [created for them](/platform/tenancy-and-attribution#scoped-turn-requirements).

```typescript tab="TypeScript"
const accounts = new Map<string, { userId: string; agentId: string }>();

export async function POST(request: Request) {
  const token = request.headers.get("authorization")?.replace("Bearer ", "");
  const account = token ? accounts.get(token) : undefined;
  if (!account) {
    return new Response("unauthorized", { status: 401 });
  }
  const { message, sessionId } = await request.json();
  const result = await client.forUser(account.userId).chat({
    agentId: account.agentId,
    message,
    ...(sessionId ? { sessionId } : {}),
    abortSignal: request.signal,
  });
  return result.toResponse();
}
```

```python tab="Python"
from blazing_agents import AsyncBlazingAgents
from fastapi import FastAPI, Request
from fastapi.responses import JSONResponse, StreamingResponse

app = FastAPI()
client = AsyncBlazingAgents()
accounts: dict[str, tuple[str, str]] = {}


@app.post("/api/chat")
async def chat(request: Request) -> StreamingResponse | JSONResponse:
    token = request.headers.get("authorization", "").removeprefix("Bearer ")
    if token not in accounts:
        return JSONResponse({"error": "unauthorized"}, status_code=401)
    user_id, user_agent_id = accounts[token]
    body = await request.json()
    session_id = body.get("sessionId")
    stream = await client.for_user(user_id).chat(
        agent_id=user_agent_id,
        message=body["message"],
        **({"session_id": session_id} if session_id else {}),
    )
    headers = {"x-vercel-ai-ui-message-stream": "v1"}
    if location := stream.headers.get("location"):
        headers["location"] = location
    return StreamingResponse(stream, headers=headers, media_type="text/event-stream")
```

```rust tab="Rust"
use std::collections::HashMap;
use std::sync::Arc;

use axum::body::Body;
use axum::extract::State;
use axum::http::{header, HeaderMap, HeaderValue, StatusCode};
use axum::response::Response;
use axum::routing::post;
use axum::{Json, Router};
use blazing_agents::messages::UserMessage;
use blazing_agents::Client;
use serde::Deserialize;

/// Maps a session token to the user ID and that user's agent ID.
type Accounts = Arc<HashMap<String, (String, String)>>;

#[derive(Deserialize)]
#[serde(rename_all = "camelCase")]
struct ChatRequest {
    message: UserMessage,
    session_id: Option<String>,
}

async fn chat(
    State((client, accounts)): State<(Client, Accounts)>,
    headers: HeaderMap,
    Json(body): Json<ChatRequest>,
) -> Result<Response, StatusCode> {
    let (user_id, user_agent_id) = headers
        .get(header::AUTHORIZATION)
        .and_then(|value| value.to_str().ok())
        .and_then(|value| value.strip_prefix("Bearer "))
        .and_then(|token| accounts.get(token))
        .ok_or(StatusCode::UNAUTHORIZED)?;
    let user_client = client
        .for_user(user_id)
        .map_err(|_| StatusCode::INTERNAL_SERVER_ERROR)?;
    let call = user_client.chat(user_agent_id, body.message);
    let stream = match body.session_id {
        Some(session_id) => call.session(session_id).await,
        None => call.await,
    }
    .map_err(|error| {
        error
            .status()
            .and_then(|status| StatusCode::from_u16(status).ok())
            .unwrap_or(StatusCode::INTERNAL_SERVER_ERROR)
    })?;

    let location = stream.meta().headers().get(header::LOCATION).cloned();
    let mut response = Response::new(Body::from_stream(stream));
    let headers = response.headers_mut();
    headers.insert(
        "x-vercel-ai-ui-message-stream",
        HeaderValue::from_static("v1"),
    );
    headers.insert(
        header::CONTENT_TYPE,
        HeaderValue::from_static("text/event-stream"),
    );
    if let Some(location) = location {
        headers.insert(header::LOCATION, location);
    }
    Ok(response)
}

let accounts: Accounts = Arc::new(HashMap::new());
let app: Router = Router::new()
    .route("/api/chat", post(chat))
    .with_state((client, accounts));
```

```go tab="Go"
type chatRequest struct {
	Message   ba.UserMessage `json:"message"`
	SessionID ba.SessionID   `json:"sessionId"`
}

type account struct {
	UserID  string
	AgentID ba.AgentID
}

accounts := map[string]account{}

http.HandleFunc("POST /api/chat", func(w http.ResponseWriter, r *http.Request) {
	user, ok := accounts[strings.TrimPrefix(r.Header.Get("Authorization"), "Bearer ")]
	if !ok {
		http.Error(w, "unauthorized", http.StatusUnauthorized)
		return
	}
	var body chatRequest
	if err := json.NewDecoder(r.Body).Decode(&body); err != nil {
		http.Error(w, "invalid request", http.StatusBadRequest)
		return
	}
	userClient, err := client.ForUser(user.UserID)
	if err != nil {
		http.Error(w, "invalid user", http.StatusInternalServerError)
		return
	}
	stream, err := userClient.Chat.Send(r.Context(), user.AgentID, ba.Messages(body.Message),
		ba.ChatParams{SessionID: body.SessionID})
	if err != nil {
		status := http.StatusInternalServerError
		var apiErr *ba.APIError
		if errors.As(err, &apiErr) {
			status = apiErr.Status
		}
		http.Error(w, http.StatusText(status), status)
		return
	}
	defer stream.Close()

	stream.SetRelayHeaders(w.Header())
	if location := stream.Meta().Header.Get("Location"); location != "" {
		w.Header().Set("Location", location)
	}
	stream.WriteTo(w)
})
return nil
```

Without a `sessionId`, the call starts a new session and the response carries its ID in the `location` header. On the frontend, `useChat` with `BlazingAgentsChatTransport` renders the stream, reads that header, and sends the session ID back on the next message. A session ID that belongs to another user returns [`not_found`](/api-reference/protocols/errors#not_found). [Build a chatbot](/getting-started/chatbot) shows the full frontend.

### What to add next [#relay-what-to-add-next]

Before real users reach this endpoint, replace the demo pieces. In TypeScript, [`createChatRelay`](/sdk/typescript/chat-transport) does the relay part for you; [connect Blazing Agents to your app](/getting-started/connect-your-app) shows it, and the same endpoint in Python, Rust, and Go.

- **Sign-in.** Find out who the user is from your own sign-in, never from the request body, and reject the request if you cannot.
- **One agent per user.** Create each user's agent once with the scoped client and store its ID with the user. A scoped turn needs an agent and workspace of that user's own, and one agent shared by every user would also share its files. See [what a scoped turn needs](/platform/tenancy-and-attribution#scoped-turn-requirements).
- **Stopping.** In TypeScript, pass `abortSignal: request.signal`, as above, so a user who closes the tab stops the turn.

A chat stream has one reader. In TypeScript, call either `toResponse()` or `toStream()` once; a second call throws `stream_error`. `sessionId` stays available either way.

## Send an image [#send-an-image]

A user message can mix text parts with image `file` parts. Each image needs an `image/*` media type and the image itself as a base64 `data:` URL. A remote URL, such as `https://...`, returns [`validation_failed`](/api-reference/protocols/errors#validation_failed):

```typescript tab="TypeScript"
import { readFile } from "node:fs/promises";

const imageUrl = `data:image/png;base64,${(await readFile("diagram.png")).toString("base64")}`;
const result = await client.chat({
  agentId,
  message: {
    id: crypto.randomUUID(),
    role: "user",
    parts: [
      { type: "text", text: "Describe this diagram." },
      { type: "file", mediaType: "image/png", url: imageUrl },
    ],
  },
});
```

```python tab="Python"
import base64
import uuid

with open("diagram.png", "rb") as file:
    image_url = "data:image/png;base64," + base64.b64encode(file.read()).decode()

message = {
    "id": str(uuid.uuid4()),
    "role": "user",
    "parts": [
        {"type": "text", "text": "Describe this diagram."},
        {"type": "file", "mediaType": "image/png", "url": image_url},
    ],
}
with client.chat(agent_id=agent_id, message=message) as stream:
    for chunk in stream:
        print(chunk.decode(), end="")
```

```rust tab="Rust"
use base64::{engine::general_purpose::STANDARD, Engine as _};
use blazing_agents::messages::{UserMessage, UserPart};
use futures_util::TryStreamExt;

let image_url = format!(
    "data:image/png;base64,{}",
    STANDARD.encode(std::fs::read("diagram.png")?)
);
let message = UserMessage::text("Describe this diagram.")
    .part(UserPart::file("image/png", image_url));
let mut stream = client.chat(agent_id, message).await?;
while let Some(chunk) = stream.try_next().await? {
    print!("{}", String::from_utf8_lossy(&chunk));
}
```

```go tab="Go"
image, err := os.ReadFile("diagram.png")
if err != nil {
	return err
}
imageURL := "data:image/png;base64," + base64.StdEncoding.EncodeToString(image)

message := ba.TextMessage("Describe this diagram.")
message.Parts = append(message.Parts, ba.FilePart{MediaType: "image/png", URL: imageURL})
stream, err := client.Chat.Send(ctx, agentID, ba.Messages(message), ba.ChatParams{})
if err != nil {
	return err
}
defer stream.Close()
_, err = stream.WriteTo(os.Stdout)
return err
```

The image is part of the message only. It is not saved to the workspace or published as an artifact. Check the media type, source, and size in your backend before you send it.

## Regenerate an answer [#regenerate-an-answer]

Pass `trigger: "regenerate-message"` (`client.regenerate()` in Rust, `client.Chat.Regenerate()` in Go) on an existing session to replace an answer. Without `messageId`, the latest answer is replaced. With the ID of an earlier assistant message, that answer and everything after it is replaced. With the ID of a user message, that message is removed and the one you send takes its place.

```typescript tab="TypeScript"
const result = await client.chat({
  agentId,
  sessionId,
  message,
  trigger: "regenerate-message",
  messageId: assistantMessageId,
});
```

```python tab="Python"
with client.chat(
    agent_id=agent_id,
    session_id=session_id,
    message=message,
    trigger="regenerate-message",
    message_id=assistant_message_id,
) as stream:
    for chunk in stream:
        print(chunk.decode(), end="")
```

```rust tab="Rust"
use blazing_agents::messages::UserMessage;
use futures_util::TryStreamExt;

let message = UserMessage::text("Say hello in one short sentence.");
let assistant_message_id = "msg_0123456789abcdef";
let mut stream = client
    .regenerate(agent_id, session_id, message)
    .message_id(assistant_message_id)
    .await?;
while let Some(chunk) = stream.try_next().await? {
    print!("{}", String::from_utf8_lossy(&chunk));
}
```

```go tab="Go"
message := ba.TextMessage("Say hello in one short sentence.")
assistantMessageID := "msg_0123456789abcdef"
stream, err := client.Chat.Regenerate(ctx, agentID, sessionID, message, ba.RegenerateParams{
	MessageID: &assistantMessageID,
})
if err != nil {
	return err
}
defer stream.Close()
_, err = stream.WriteTo(os.Stdout)
return err
```

The old answer stays until the new one succeeds. If regeneration fails or you stop it, the session is unchanged.

## Stops, errors, and what gets saved [#stops-errors-and-what-gets-saved]

- **Stopping.** Pass an `AbortSignal` as `abortSignal`, or cancel the stream you are reading. The turn stops, and usage up to that point is recorded.
- **Errors before streaming.** Problems such as an unknown agent, a bad request, or an exhausted spending limit reject the call with a typed error. Nothing is saved and nothing is charged.
- **Time limit.** A turn still running at the [turn deadline](/api-reference/protocols/service-limits#turn-deadline) is stopped like a cancelled one, and the history stays as it was.
- **Errors during streaming.** A chat stream ends with an `{ type: "error", errorText }` event, which AI SDK clients already understand. For completion, `textStream` throws, and `await result.text` rejects with a `stream_error`.
- **Saved history.** A successful chat turn adds the exchange to the session. A failed or stopped turn leaves the history as it was. The exception is a turn that a [model spending limit](/platform/usage-and-spending-limits#spending-limit-stops) stops partway, which keeps the output it finished. Completion never saves history.

Tools that need [approval](/agents/tools/tool-approvals) cannot wait for a person during `client.completion()`, because there is no session to resume. Those calls are blocked, and the agent carries on with the work it is allowed to do.
