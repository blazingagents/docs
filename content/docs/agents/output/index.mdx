# Output

An Agent can produce conversational or standalone text, or a stateless object constrained by JSON Schema. Both output modes run a metered Turn with the Agent's resolved configuration.

## What output shares [#what-output-shares]

Every output request resolves an [Agent](/agents), creates a Turn, applies quotas, and records usage after success, failure, or cancellation. The output mode determines whether a [Session](/platform/sessions-and-turns) and transcript are involved.

Use [generation and streaming](/agents/output/generation-and-streaming) for conversational UI or free-form text. Use [structured output](/agents/output/structured-output) when application code needs a known data shape.
