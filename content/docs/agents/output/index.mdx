# Output

Your agent can answer in two ways. Stream text for people to read, in a conversation or as a one-off, or return JSON in a shape you define for your code to use.

## Which one to use [#which-one-to-use]

| You want | Use |
| --- | --- |
| A chat interface that remembers the conversation | `client.chat()` |
| A summary, rewrite, or other standalone text | `client.completion()` |
| Data your code acts on, such as a category or extracted fields | `client.object()` |

All three run the same agent, with its model, instructions, and tools, and all three count toward your [usage and quotas](/platform/usage-and-quotas). Only chat keeps history in a [session](/platform/sessions-and-turns).
