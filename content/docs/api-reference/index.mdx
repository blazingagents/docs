# API Reference

Call Blazing Agents over plain HTTP from any backend language. The REST pages
list every endpoint with its request, response, errors, and a cURL example. The
protocol pages cover the formats those endpoints share: objects, errors,
streams, IDs, pagination, and limits.

If you work in TypeScript or Python, the [TypeScript SDK](/sdk/typescript) and
[Python SDK](/sdk/python) wrap the same endpoints and are the faster path.
