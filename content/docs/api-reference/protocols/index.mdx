# Protocols and contracts

These pages define rules shared by multiple SDK methods and REST endpoints.
Use them when you need the exact wire behavior or data contract rather than one
operation's signature.

## Examples [#examples]

An SDK stream uses the [streaming contract](/api-reference/protocols/streaming)
and the shared [error contract](/api-reference/protocols/errors):

```typescript
const result = await client.completion({ agentId, prompt: "Summarize this." });

for await (const delta of result.textStream) {
  process.stdout.write(delta);
}
```

A REST list operation combines IDs, pagination, returned objects, errors, and
limits:

```bash
curl "$BLAZING_AGENTS_BASE_URL/v1/agents/$AGENT_ID/sessions?limit=50" \
  -H "Authorization: Bearer $BLAZING_AGENTS_API_KEY"
```
