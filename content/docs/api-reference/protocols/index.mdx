## Examples [#examples]

Streaming a completion follows the [streaming protocol](/api-reference/protocols/streaming)
and reports failures through the [error contract](/api-reference/protocols/errors):

```typescript tab="TypeScript"
const result = await client.completion({ agentId, prompt: "Summarize this." });

for await (const delta of result.textStream) {
  process.stdout.write(delta);
}
```

```python tab="Python"
with client.completion_stream(agent_id=agent_id, prompt="Summarize this.") as stream:
    for delta in stream:
        print(delta, end="", flush=True)
```

Listing sessions over REST uses IDs, pagination, objects, errors, and limits
together:

```bash
curl "$BLAZING_AGENTS_BASE_URL/v1/agents/$AGENT_ID/sessions?limit=50" \
  -H "Authorization: Bearer $BLAZING_AGENTS_API_KEY"
```
