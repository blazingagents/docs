## How the controls fit together [#how-the-controls-fit-together]

1. A backend credential establishes the Tenant for a request.
2. Optional end-user attribution labels supported resources and usage without granting access.
3. A Turn executes, optionally inside a Session, and settles usage.
4. Quotas, service limits, and lifecycle rules determine whether work starts, retries safely, or reaches a terminal outcome.

The public API is backend-only. Your application authenticates its users and authorizes access before it calls Blazing Agents.
