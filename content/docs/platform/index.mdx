## How a request flows [#how-a-request-flows]

1. Your backend signs in the user, checks what they may access, and calls Blazing Agents with your API key.
2. You can pass a `userId` to label the work for reporting. It does not grant access.
3. The agent runs a turn, inside a session if you want history, and its usage is recorded.
4. Quotas and service limits decide whether the turn starts, and the error code tells you whether to retry.
