# Automation

Run your agent with no user waiting: nightly reports, inbox triage, data refreshes. You save the job once as a task, start it from your code or on a schedule, and read each run's result when it is done.

## Choose how to start work [#choose-how-to-start-work]

| You want to | Use |
| --- | --- |
| Start work from your code, without duplicates | An on-demand [task](/automation/tasks) and a [task run](/automation/task-runs) with an idempotency key |
| Run at one known time | A [one-time schedule](/automation/schedules#choose-a-schedule) |
| Repeat every few minutes or hours | An [interval schedule](/automation/schedules#choose-a-schedule) |
| Follow the calendar, such as weekdays at 9:00 | A [cron schedule](/automation/schedules#choose-a-schedule) |

Each run that executes gets its own fresh [session](/platform/sessions-and-turns), so you can read its transcript and any [artifacts](/agents/artifacts) it published.
