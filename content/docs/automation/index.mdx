# Automation

Automation runs an Agent outside an interactive request. A Task stores what should run, a Task run records one execution, and a schedule determines when the platform should create runs.

## Choose an execution path [#choose-an-execution-path]

| Need | Use |
| --- | --- |
| Submit durable work from application code | An on-demand [Task](/automation/tasks) and an idempotent [Task run](/automation/task-runs) |
| Run at a known instant | A [one-time schedule](/automation/schedules#choose-a-schedule) |
| Repeat by elapsed time | An [interval schedule](/automation/schedules#choose-a-schedule) |
| Follow calendar boundaries | A [cron schedule](/automation/schedules#choose-a-schedule) |

Each executing run receives a fresh [Session](/platform/sessions-and-turns), so you can inspect its transcript and published Artifacts after execution.
