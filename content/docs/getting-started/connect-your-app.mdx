# Connect Blazing Agents to your app

Add one chat endpoint to your backend. It checks who the user is, sends their message to that user's own agent, and streams the answer back. The same endpoint returns the stored conversation and passes on messages the user sends while the agent works, which is everything the [React chat hook](/sdk/typescript/use-blazing-agents-chat) needs. Blazing Agents keeps the conversation history and lets each user open only their own conversations, so your endpoint stores just one agent ID per user.

## Before you begin [#before-you-begin]

Finish [Run your first agent](/getting-started/quickstart) and keep the same project folder and terminal. Set the provider ID it printed, and two demo tokens that stand in for your own sign-in:

```bash
export BLAZING_AGENTS_PROVIDER_ID="prv_..."
export DEMO_USER_TOKEN="demo-token"
export OTHER_USER_TOKEN="other-token"
```

The endpoint creates agents, so `BLAZING_AGENTS_API_KEY` must be the full-access key from [setup](/getting-started/setup).

<Callout type="warn" title="Keep credentials on the backend">
  Your browser or mobile app talks only to your backend. It never receives the Blazing Agents API key.
</Callout>

    ## Add a chat endpoint [#add-a-chat-endpoint]

    Save this as `server.ts`, `server.py`, `src/bin/server.rs`, or `server/main.go`. The `users` map stands in for your sign-in, and the map of agent IDs stands in for your database.

    ```typescript tab="TypeScript" tab-group="sdk-language" title="server.ts"
    import { serve } from "@hono/node-server";
    import { BlazingAgents, createChatRelay } from "@blazingagents/sdk";
    import { Hono } from "hono";

    const client = new BlazingAgents({
      apiKey: process.env.BLAZING_AGENTS_API_KEY!,
    });

    // Replace these with your own sign-in check and database.
    const users = new Map([
      [process.env.DEMO_USER_TOKEN!, "user-1"],
      [process.env.OTHER_USER_TOKEN!, "user-2"],
    ]);
    const agentIds = new Map<string, string>();

    async function agentFor(userId: string) {
      let agentId = agentIds.get(userId);
      if (!agentId) {
        const agent = await client.forUser(userId).agents.create({
          name: "Chat agent",
          providerId: process.env.BLAZING_AGENTS_PROVIDER_ID!,
          model: "openai/gpt-6-luna",
        });
        agentId = agent.id;
        agentIds.set(userId, agentId);
      }
      return agentId;
    }

    const relayChat = createChatRelay({
      client,
      async resolveContext(request) {
        const token = request.headers.get("authorization")?.replace("Bearer ", "");
        const userId = token ? users.get(token) : undefined;
        return userId ? { agentId: await agentFor(userId), userId } : null;
      },
    });

    const app = new Hono();
    app.post("/api/chat", (c) => relayChat(c.req.raw));
    serve({ fetch: app.fetch, port: 8787 });
    ```

    ```python tab="Python" title="server.py"
    import os

    from blazing_agents import APIStatusError, AsyncBlazingAgents
    from fastapi import FastAPI, Request
    from fastapi.responses import JSONResponse, StreamingResponse

    client = AsyncBlazingAgents()
    app = FastAPI()

    # Replace these with your own sign-in check and database.
    users = {
        os.environ["DEMO_USER_TOKEN"]: "user-1",
        os.environ["OTHER_USER_TOKEN"]: "user-2",
    }
    agent_ids: dict[str, str] = {}


    async def agent_for(user_id: str) -> str:
        if user_id not in agent_ids:
            agent = await client.for_user(user_id).agents.create(
                name="Chat agent",
                provider_id=os.environ["BLAZING_AGENTS_PROVIDER_ID"],
                model="openai/gpt-6-luna",
            )
            agent_ids[user_id] = agent.id
        return agent_ids[user_id]


    @app.post("/api/chat")
    async def chat(request: Request):
        token = request.headers.get("authorization", "").removeprefix("Bearer ")
        user_id = users.get(token)
        if user_id is None:
            return JSONResponse(
                {"error": {"code": "unauthorized", "message": "Sign in first."}},
                status_code=401,
            )

        user = client.for_user(user_id)
        body = await request.json()
        try:
            agent_id = await agent_for(user_id)
            if body["op"] == "history":
                cursor = {"cursor": body["cursor"]} if "cursor" in body else {}
                page = await user.sessions.messages(
                    agent_id=agent_id, session_id=body["sessionId"], limit=200, **cursor
                )
                data = [m.model_dump(mode="json", by_alias=True, exclude_unset=True) for m in page.data]
                return {"data": data, "nextCursor": page.next_cursor}
            if body["op"] == "steer":
                receipt = await user.sessions.submit_input(
                    agent_id=agent_id,
                    session_id=body["sessionId"],
                    request_id=body["requestId"],
                    message=body["message"],
                )
                return JSONResponse({"state": receipt.data.state}, status_code=202)
            session = {"session_id": body["sessionId"]} if body.get("sessionId") else {}
            stream = await user.chat(
                agent_id=agent_id,
                message=body["message"],
                trigger=body.get("trigger", "submit-message"),
                **session,
            )
        except APIStatusError as error:
            return JSONResponse(
                {"error": {"code": error.code, "message": error.message}},
                status_code=error.status_code,
            )
        headers = {"cache-control": "no-cache", "x-vercel-ai-ui-message-stream": "v1"}
        if "location" in stream.headers:
            headers["location"] = stream.headers["location"]
        return StreamingResponse(stream, media_type="text/event-stream", headers=headers)
    ```

    ```rust tab="Rust" title="src/bin/server.rs"
    use axum::body::Body;
    use axum::extract::State;
    use axum::http::{HeaderMap, HeaderValue, StatusCode};
    use axum::response::{IntoResponse, Response};
    use axum::routing::post;
    use axum::{Json, Router};
    use blazing_agents::ids::AgentId;
    use blazing_agents::messages::UserMessage;
    use blazing_agents::{Client, UserClient};
    use serde::Deserialize;
    use serde_json::json;
    use std::collections::HashMap;
    use std::sync::{Arc, Mutex};
    use tokio::net::TcpListener;

    #[derive(Deserialize)]
    #[serde(tag = "op", rename_all = "lowercase", rename_all_fields = "camelCase")]
    enum RelayRequest {
        Chat {
            message: UserMessage,
            session_id: Option<String>,
            trigger: Option<String>,
        },
        History {
            session_id: String,
            cursor: Option<String>,
        },
        Steer {
            session_id: String,
            request_id: String,
            message: UserMessage,
        },
    }

    struct AppState {
        client: Client,
        provider_id: String,
        // Replace these with your own sign-in check and database.
        users: HashMap<String, String>,
        agent_ids: Mutex<HashMap<String, AgentId>>,
    }

    fn error_response(error: blazing_agents::Error) -> Response {
        let (status, code, message) = match &error {
            blazing_agents::Error::Api(api) => (api.status(), api.code().to_string(), api.message().to_owned()),
            _ => (502, "network_error".to_owned(), error.to_string()),
        };
        let status = StatusCode::from_u16(status).unwrap_or(StatusCode::BAD_GATEWAY);
        (status, Json(json!({ "error": { "code": code, "message": message } }))).into_response()
    }

    async fn chat(
        State(state): State<Arc<AppState>>,
        headers: HeaderMap,
        Json(body): Json<RelayRequest>,
    ) -> Result<Response, Response> {
        let token = headers
            .get("authorization")
            .and_then(|value| value.to_str().ok())
            .map(|value| value.trim_start_matches("Bearer "))
            .unwrap_or_default();
        let Some(user_id) = state.users.get(token).cloned() else {
            let body = json!({ "error": { "code": "unauthorized", "message": "Sign in first." } });
            return Err((StatusCode::UNAUTHORIZED, Json(body)).into_response());
        };
        let user = state
            .client
            .for_user(&user_id)
            .map_err(|_| StatusCode::INTERNAL_SERVER_ERROR.into_response())?;

        let stored = state.agent_ids.lock().unwrap().get(&user_id).cloned();
        let agent_id = match stored {
            Some(agent_id) => agent_id,
            None => {
                let agent = user
                    .agents()
                    .create("Chat agent")
                    .model(&state.provider_id, "openai/gpt-6-luna")
                    .await
                    .map_err(error_response)?;
                state
                    .agent_ids
                    .lock()
                    .unwrap()
                    .insert(user_id, agent.id.clone());
                agent.id
            }
        };
        relay(&user, agent_id.as_str(), body)
            .await
            .map_err(error_response)
    }

    async fn relay(
        user: &UserClient,
        agent_id: &str,
        request: RelayRequest,
    ) -> Result<Response, blazing_agents::Error> {
        match request {
            RelayRequest::Chat { message, session_id, trigger } => {
                let stream = match (session_id, trigger.as_deref()) {
                    (Some(id), Some("regenerate-message")) => user.regenerate(agent_id, id, message).await?,
                    (Some(id), _) => user.chat(agent_id, message).session(id).await?,
                    (None, _) => user.chat(agent_id, message).await?,
                };
                let location = stream.meta().headers().get("location").cloned();
                let mut response = Response::new(Body::from_stream(stream));
                let headers = response.headers_mut();
                headers.insert("content-type", HeaderValue::from_static("text/event-stream"));
                headers.insert("cache-control", HeaderValue::from_static("no-cache"));
                headers.insert("x-vercel-ai-ui-message-stream", HeaderValue::from_static("v1"));
                if let Some(location) = location {
                    headers.insert("location", location);
                }
                Ok(response)
            }
            RelayRequest::History { session_id, cursor } => {
                let mut page = user.sessions().messages(agent_id, session_id).limit(200);
                if let Some(cursor) = cursor {
                    page = page.cursor(cursor.into());
                }
                Ok(Json(page.await?).into_response())
            }
            RelayRequest::Steer { session_id, request_id, message } => {
                let receipt = user
                    .sessions()
                    .submit_input(agent_id, session_id, request_id, message)
                    .await?;
                Ok((StatusCode::ACCEPTED, Json(json!({ "state": receipt.input.state }))).into_response())
            }
        }
    }

    #[tokio::main]
    async fn main() -> Result<(), Box<dyn std::error::Error>> {
        let state = Arc::new(AppState {
            client: Client::from_env()?,
            provider_id: std::env::var("BLAZING_AGENTS_PROVIDER_ID")?,
            users: HashMap::from([
                (std::env::var("DEMO_USER_TOKEN")?, "user-1".to_string()),
                (std::env::var("OTHER_USER_TOKEN")?, "user-2".to_string()),
            ]),
            agent_ids: Mutex::new(HashMap::new()),
        });
        let app = Router::new()
            .route("/api/chat", post(chat))
            .with_state(state);
        let listener = TcpListener::bind("0.0.0.0:8787").await?;
        axum::serve(listener, app).await?;
        Ok(())
    }
    ```

    ```go tab="Go" title="server/main.go"
    package main

    import (
    	"context"
    	"encoding/json"
    	"errors"
    	"log"
    	"net/http"
    	"os"
    	"strings"
    	"sync"

    	ba "github.com/blazingagents/golang-sdk"
    )

    type relayRequest struct {
    	Op        string         `json:"op"`
    	Message   ba.UserMessage `json:"message"`
    	SessionID ba.SessionID   `json:"sessionId"`
    	Trigger   string         `json:"trigger"`
    	Cursor    string         `json:"cursor"`
    	RequestID string         `json:"requestId"`
    }

    type app struct {
    	client     *ba.Client
    	providerID ba.ProviderID
    	// Replace these with your own sign-in check and database.
    	users    map[string]string
    	mu       sync.Mutex
    	agentIDs map[string]ba.AgentID
    }

    func writeJSON(w http.ResponseWriter, status int, body any) {
    	w.Header().Set("Content-Type", "application/json")
    	w.WriteHeader(status)
    	json.NewEncoder(w).Encode(body)
    }

    func writeError(w http.ResponseWriter, status int, code, message string) {
    	writeJSON(w, status, map[string]any{"error": map[string]string{"code": code, "message": message}})
    }

    func writeAPIError(w http.ResponseWriter, err error) {
    	var apiErr *ba.APIError
    	if errors.As(err, &apiErr) {
    		writeError(w, apiErr.Status, string(apiErr.Code), apiErr.Message)
    		return
    	}
    	writeError(w, http.StatusBadGateway, "network_error", err.Error())
    }

    func (a *app) agentFor(ctx context.Context, user *ba.UserClient, userID string) (ba.AgentID, error) {
    	a.mu.Lock()
    	agentID, ok := a.agentIDs[userID]
    	a.mu.Unlock()
    	if ok {
    		return agentID, nil
    	}
    	agent, err := user.Agents.Create(ctx, ba.CreateAgentParams{
    		Name:       "Chat agent",
    		ProviderID: ba.Value(a.providerID),
    		Model:      ba.Value("openai/gpt-6-luna"),
    	})
    	if err != nil {
    		return "", err
    	}
    	a.mu.Lock()
    	a.agentIDs[userID] = agent.ID
    	a.mu.Unlock()
    	return agent.ID, nil
    }

    func (a *app) chat(w http.ResponseWriter, r *http.Request) {
    	token := strings.TrimPrefix(r.Header.Get("Authorization"), "Bearer ")
    	userID, ok := a.users[token]
    	if !ok {
    		writeError(w, http.StatusUnauthorized, "unauthorized", "Sign in first.")
    		return
    	}
    	user, err := a.client.ForUser(userID)
    	if err != nil {
    		writeAPIError(w, err)
    		return
    	}

    	var body relayRequest
    	if err := json.NewDecoder(r.Body).Decode(&body); err != nil {
    		writeError(w, http.StatusBadRequest, "invalid_request", "Invalid request body.")
    		return
    	}
    	agentID, err := a.agentFor(r.Context(), user, userID)
    	if err != nil {
    		writeAPIError(w, err)
    		return
    	}

    	switch body.Op {
    	case "history":
    		limit := 200
    		params := ba.ListSessionMessagesParams{Limit: &limit}
    		if body.Cursor != "" {
    			params.Cursor = &body.Cursor
    		}
    		page, err := user.Sessions.ListMessages(r.Context(), agentID, body.SessionID, params)
    		if err != nil {
    			writeAPIError(w, err)
    			return
    		}
    		var next *string
    		if page.NextCursor != "" {
    			next = &page.NextCursor
    		}
    		writeJSON(w, http.StatusOK, map[string]any{"data": page.Data, "nextCursor": next})
    	case "steer":
    		receipt, err := user.Sessions.SubmitInput(r.Context(), agentID, body.SessionID,
    			ba.SubmitSessionInputParams{RequestID: body.RequestID, Message: body.Message})
    		if err != nil {
    			writeAPIError(w, err)
    			return
    		}
    		writeJSON(w, http.StatusAccepted, map[string]any{"state": receipt.Input.State})
    	default:
    		var stream *ba.ChatStream
    		if body.Trigger == "regenerate-message" && body.SessionID != "" {
    			stream, err = user.Chat.Regenerate(r.Context(), agentID, body.SessionID, body.Message,
    				ba.RegenerateParams{})
    		} else {
    			stream, err = user.Chat.Send(r.Context(), agentID, ba.Messages(body.Message),
    				ba.ChatParams{SessionID: body.SessionID})
    		}
    		if err != nil {
    			writeAPIError(w, err)
    			return
    		}
    		defer stream.Close()

    		stream.SetRelayHeaders(w.Header())
    		if location := stream.Meta().Header.Get("Location"); location != "" {
    			w.Header().Set("Location", location)
    		}
    		if _, err := stream.WriteTo(w); err != nil {
    			log.Printf("relay ended: %v", err)
    		}
    	}
    }

    func main() {
    	client, err := ba.NewClient()
    	if err != nil {
    		log.Fatal(err)
    	}
    	a := &app{
    		client:     client,
    		providerID: ba.ProviderID(os.Getenv("BLAZING_AGENTS_PROVIDER_ID")),
    		users: map[string]string{
    			os.Getenv("DEMO_USER_TOKEN"):  "user-1",
    			os.Getenv("OTHER_USER_TOKEN"): "user-2",
    		},
    		agentIDs: map[string]ba.AgentID{},
    	}
    	http.HandleFunc("POST /api/chat", a.chat)
    	log.Fatal(http.ListenAndServe(":8787", nil))
    }
    ```

    Start it with `node server.ts`, `uvicorn server:app --port 8787`, `cargo run --bin server`, or `go run ./server`.

    ## Verify the integration [#verify-the-integration]

    In a second terminal, export `DEMO_USER_TOKEN` and `OTHER_USER_TOKEN` again and ask the agent to remember something:

    ```bash
    curl -i -N http://localhost:8787/api/chat \
      -H "authorization: Bearer $DEMO_USER_TOKEN" \
      -H "content-type: application/json" \
      -d '{"op":"chat","message":{"id":"m1","role":"user","parts":[{"type":"text","text":"Remember the word cobalt."}]}}'
    ```

    The answer streams in as `data: {...}` lines. Among the response headers is a `location` header that ends in the new `ss_...` session ID. Send it back with a follow-up question:

    ```bash
    curl -N http://localhost:8787/api/chat \
      -H "authorization: Bearer $DEMO_USER_TOKEN" \
      -H "content-type: application/json" \
      -d '{"op":"chat","sessionId":"ss_...","message":{"id":"m2","role":"user","parts":[{"type":"text","text":"Which word did I ask you to remember?"}]}}'
    ```

    The agent answers "cobalt", because Blazing Agents kept the first exchange. Read the stored conversation the way the browser does after a reload:

    ```bash
    curl http://localhost:8787/api/chat \
      -H "authorization: Bearer $DEMO_USER_TOKEN" \
      -H "content-type: application/json" \
      -d '{"op":"history","sessionId":"ss_..."}'
    ```

    You get `{"data":[...],"nextCursor":null}`, with both questions and both answers in `data`. Now send the same session ID as the other user:

    ```bash
    curl -i http://localhost:8787/api/chat \
      -H "authorization: Bearer $OTHER_USER_TOKEN" \
      -H "content-type: application/json" \
      -d '{"op":"chat","sessionId":"ss_...","message":{"id":"m3","role":"user","parts":[{"type":"text","text":"Which word did I ask you to remember?"}]}}'
    ```

    You get `404`, because the session belongs to the first user. Leave out the `authorization` header and you get `401`.

## What happened [#persist-and-resume-the-session]

The first request from each user finds no stored agent ID, so the endpoint creates an agent with a client scoped to that user: `client.forUser(userId)` in TypeScript, `client.for_user(user_id)` in Python and Rust, and `client.ForUser(userID)` in Go. The new agent and the workspace it comes with belong to that user. The endpoint then sends the message through the same scoped client.

A request without a `sessionId` starts a new session that belongs to the user, and Blazing Agents returns its ID before the answer finishes streaming. A later request with that `sessionId` continues the conversation, and the agent sees everything said so far. Your frontend sends only the newest message each time. The scoped client reaches only that user's agents, sessions, and workspaces, so a session ID from anyone else returns `404` and you keep no table of who owns which conversation.

Each user gets their own agent because every turn of an agent runs in that agent's one workspace. If all your users chatted with one shared agent, their turns would share one workspace, and one user's files would be readable from another user's turns. See [tenancy and attribution](/platform/tenancy-and-attribution) for how agents, workspaces, and sessions belong to your users.

The request body's `op` says what the browser needs. `chat` runs a turn, `history` returns one page of the stored conversation, and `steer` sends a message into the turn that is running. In TypeScript, `createChatRelay` answers all three for you. It scopes each request to the `userId` that `resolveContext` returns, and it passes the request's abort signal along, so a user who presses Stop or closes the tab stops the turn. The Python, Rust, and Go endpoints answer the same three operations by hand, as the [browser chat relay](/api-reference/protocols/browser-relay) describes. They pass the session ID only when the request has one, route a `regenerate-message` trigger to a regeneration, and return API errors as `{"error":{"code","message"}}` with the API's status, so the browser can tell a deleted session from a turn that cannot take a steer.

The agents this endpoint creates use the default approval policy, which runs every tool without asking, so no turn here waits for a person. If you turn on [human approval](/agents/tools/tool-approvals#human-approval-flow), `createChatRelay` already forwards the user's answers. In Python, Rust, and Go, add a branch that sends them through the same scoped client with `continue_chat()` in Python and Rust, or `Chat.Continue()` in Go.

## Production notes [#production-notes]

- Replace the demo tokens with your real sign-in, and store each user's agent ID with the user in your database.
- Create each user's agent once, for example when the user signs up. [Creating agents is rate-limited](/api-reference/protocols/service-limits#tenant-resource-creation-rate) per tenant, so do not create one on every request.
- Use a full-access key for a backend that creates agents. A backend that only runs agents that already exist can use a read-only key. See [API key access levels](/platform/security-and-credentials#api-key-access-levels).
- Keep the session ID even when the first turn fails or the user stops it. The conversation exists; it is empty until a turn succeeds.
- If the browser calls the endpoint from another origin, allow the `authorization` and `content-type` request headers in your CORS settings and expose the `Location` response header, so the browser can read the new session ID.
- Streams must reach the browser unbuffered. The response already sets `Cache-Control: no-cache`; make sure every proxy in front of your backend passes the stream through as it arrives.
