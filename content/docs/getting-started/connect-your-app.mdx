# Connect Blazing Agents to your app

Add one chat endpoint to your backend. It checks who the user is, sends their message to your agent, and streams the answer back. Blazing Agents keeps the conversation history, so your endpoint only has to remember which user owns which conversation.

## Before you begin [#before-you-begin]

Finish [Run your first agent](/getting-started/quickstart) and keep the same project folder and terminal. Set the agent ID it printed, and a demo token that stands in for your own sign-in:

```bash
export BLAZING_AGENTS_AGENT_ID="ag_..."
export DEMO_USER_TOKEN="demo-token"
```

<Callout type="warn" title="Keep credentials on the backend">
  Your browser or mobile app talks only to your backend. It never receives the Blazing Agents API key.
</Callout>

    ## Add a chat endpoint [#add-a-chat-endpoint]

    Save this as `server.ts`, `server.py`, `src/bin/server.rs`, or `server/main.go`. The `users` and `owners` dictionaries stand in for your sign-in and your database.

    ```typescript tab="TypeScript" tab-group="sdk-language" title="server.ts"
    import { serve } from "@hono/node-server";
    import { BlazingAgents, createChatRelay } from "@blazingagents/sdk";
    import { Hono } from "hono";

    const client = new BlazingAgents({
      apiKey: process.env.BLAZING_AGENTS_API_KEY!,
    });

    // Replace these with your own sign-in check and database.
    const users = new Map([[process.env.DEMO_USER_TOKEN!, "user-1"]]);
    const owners = new Map<string, string>();

    const relayChat = createChatRelay({
      client,
      async resolveContext(request) {
        const token = request.headers.get("authorization")?.replace("Bearer ", "");
        const userId = token ? users.get(token) : undefined;
        return userId
          ? { agentId: process.env.BLAZING_AGENTS_AGENT_ID!, userId }
          : null;
      },
      sessions: {
        async ownerOf(sessionId) {
          return owners.get(sessionId);
        },
        async recordOwner(sessionId, userId) {
          owners.set(sessionId, userId);
        },
      },
    });

    const app = new Hono();
    app.post("/api/chat", (c) => relayChat(c.req.raw));
    serve({ fetch: app.fetch, port: 8787 });
    ```

    ```python tab="Python" title="server.py"
    import os

    from blazing_agents import AsyncBlazingAgents
    from fastapi import FastAPI, Request
    from fastapi.responses import JSONResponse, StreamingResponse

    client = AsyncBlazingAgents()
    app = FastAPI()

    # Replace these with your own sign-in check and database.
    users = {os.environ["DEMO_USER_TOKEN"]: "user-1"}
    owners: dict[str, str] = {}


    @app.post("/api/chat")
    async def chat(request: Request):
        token = request.headers.get("authorization", "").removeprefix("Bearer ")
        user_id = users.get(token)
        if user_id is None:
            return JSONResponse({"error": "unauthorized"}, status_code=401)

        body = await request.json()
        session_id = body.get("sessionId")
        if session_id and owners.get(session_id) != user_id:
            return JSONResponse({"error": "forbidden"}, status_code=403)

        stream = await client.chat(
            agent_id=os.environ["BLAZING_AGENTS_AGENT_ID"],
            message=body["message"],
            trigger=body.get("trigger", "submit-message"),
            user_id=user_id,
            **({"session_id": session_id} if session_id else {}),
        )
        owners[stream.session_id] = user_id
        headers = {"cache-control": "no-cache", "x-vercel-ai-ui-message-stream": "v1"}
        if "location" in stream.headers:
            headers["location"] = stream.headers["location"]
        return StreamingResponse(stream, media_type="text/event-stream", headers=headers)
    ```

    ```rust tab="Rust" title="src/bin/server.rs"
    use axum::body::Body;
    use axum::extract::State;
    use axum::http::{HeaderMap, HeaderValue, StatusCode};
    use axum::response::{IntoResponse, Response};
    use axum::routing::post;
    use axum::{Json, Router};
    use blazing_agents::messages::UserMessage;
    use blazing_agents::Client;
    use serde::Deserialize;
    use std::collections::HashMap;
    use std::sync::{Arc, Mutex};
    use tokio::net::TcpListener;

    #[derive(Deserialize)]
    #[serde(rename_all = "camelCase")]
    struct ChatRequest {
        message: UserMessage,
        session_id: Option<String>,
        trigger: Option<String>,
    }

    struct AppState {
        client: Client,
        agent_id: String,
        // Replace these with your own sign-in check and database.
        users: HashMap<String, String>,
        owners: Mutex<HashMap<String, String>>,
    }

    async fn chat(
        State(state): State<Arc<AppState>>,
        headers: HeaderMap,
        Json(body): Json<ChatRequest>,
    ) -> Result<Response, Response> {
        let token = headers
            .get("authorization")
            .and_then(|value| value.to_str().ok())
            .map(|value| value.trim_start_matches("Bearer "))
            .unwrap_or_default();
        let Some(user_id) = state.users.get(token).cloned() else {
            return Err((
                StatusCode::UNAUTHORIZED,
                Json(serde_json::json!({ "error": "unauthorized" })),
            )
                .into_response());
        };

        if let Some(session_id) = &body.session_id {
            if state.owners.lock().unwrap().get(session_id) != Some(&user_id) {
                return Err((
                    StatusCode::FORBIDDEN,
                    Json(serde_json::json!({ "error": "forbidden" })),
                )
                    .into_response());
            }
        }

        let result = match (body.trigger.as_deref(), body.session_id) {
            (Some("regenerate-message"), Some(session_id)) => state
                .client
                .regenerate(&state.agent_id, session_id, body.message)
                .user_id(&user_id)
                .await,
            (_, session_id) => {
                let call = state
                    .client
                    .chat(&state.agent_id, body.message)
                    .user_id(&user_id);
                match session_id {
                    Some(session_id) => call.session(session_id).await,
                    None => call.await,
                }
            }
        };
        let stream = result.map_err(|error| {
            error
                .status()
                .and_then(|status| StatusCode::from_u16(status).ok())
                .unwrap_or(StatusCode::INTERNAL_SERVER_ERROR)
                .into_response()
        })?;

        state
            .owners
            .lock()
            .unwrap()
            .insert(stream.session_id().to_string(), user_id);

        let location = stream.meta().headers().get("location").cloned();
        let mut response = Response::new(Body::from_stream(stream));
        let response_headers = response.headers_mut();
        response_headers.insert("content-type", HeaderValue::from_static("text/event-stream"));
        response_headers.insert("cache-control", HeaderValue::from_static("no-cache"));
        response_headers.insert("x-vercel-ai-ui-message-stream", HeaderValue::from_static("v1"));
        if let Some(location) = location {
            response_headers.insert("location", location);
        }
        Ok(response)
    }

    #[tokio::main]
    async fn main() -> Result<(), Box<dyn std::error::Error>> {
        let state = Arc::new(AppState {
            client: Client::from_env()?,
            agent_id: std::env::var("BLAZING_AGENTS_AGENT_ID")?,
            users: HashMap::from([(std::env::var("DEMO_USER_TOKEN")?, "user-1".to_string())]),
            owners: Mutex::new(HashMap::new()),
        });
        let app = Router::new()
            .route("/api/chat", post(chat))
            .with_state(state);
        let listener = TcpListener::bind("0.0.0.0:8787").await?;
        axum::serve(listener, app).await?;
        Ok(())
    }
    ```

    ```go tab="Go" title="server/main.go"
    package main

    import (
    	"encoding/json"
    	"errors"
    	"log"
    	"net/http"
    	"os"
    	"strings"
    	"sync"

    	ba "github.com/blazingagents/golang-sdk"
    )

    type chatRequest struct {
    	Message   ba.UserMessage `json:"message"`
    	SessionID ba.SessionID   `json:"sessionId"`
    	Trigger   string         `json:"trigger"`
    }

    type app struct {
    	client  *ba.Client
    	agentID ba.AgentID
    	// Replace these with your own sign-in check and database.
    	users  map[string]string
    	mu     sync.Mutex
    	owners map[ba.SessionID]string
    }

    func writeError(w http.ResponseWriter, status int, message string) {
    	w.Header().Set("Content-Type", "application/json")
    	w.WriteHeader(status)
    	json.NewEncoder(w).Encode(map[string]string{"error": message})
    }

    func (a *app) chat(w http.ResponseWriter, r *http.Request) {
    	token := strings.TrimPrefix(r.Header.Get("Authorization"), "Bearer ")
    	userID, ok := a.users[token]
    	if !ok {
    		writeError(w, http.StatusUnauthorized, "unauthorized")
    		return
    	}

    	var body chatRequest
    	if err := json.NewDecoder(r.Body).Decode(&body); err != nil {
    		writeError(w, http.StatusBadRequest, "invalid request")
    		return
    	}
    	if body.SessionID != "" {
    		a.mu.Lock()
    		owner := a.owners[body.SessionID]
    		a.mu.Unlock()
    		if owner != userID {
    			writeError(w, http.StatusForbidden, "forbidden")
    			return
    		}
    	}

    	var stream *ba.ChatStream
    	var err error
    	if body.Trigger == "regenerate-message" && body.SessionID != "" {
    		stream, err = a.client.Chat.Regenerate(r.Context(), a.agentID, body.SessionID, body.Message,
    			ba.RegenerateParams{UserID: &userID})
    	} else {
    		stream, err = a.client.Chat.Send(r.Context(), a.agentID, ba.Messages(body.Message),
    			ba.ChatParams{SessionID: body.SessionID, UserID: &userID})
    	}
    	if err != nil {
    		status := http.StatusInternalServerError
    		var apiErr *ba.APIError
    		if errors.As(err, &apiErr) {
    			status = apiErr.Status
    		}
    		writeError(w, status, http.StatusText(status))
    		return
    	}
    	defer stream.Close()

    	a.mu.Lock()
    	a.owners[stream.SessionID()] = userID
    	a.mu.Unlock()

    	stream.SetRelayHeaders(w.Header())
    	if location := stream.Meta().Header.Get("Location"); location != "" {
    		w.Header().Set("Location", location)
    	}
    	if _, err := stream.WriteTo(w); err != nil {
    		log.Printf("relay ended: %v", err)
    	}
    }

    func main() {
    	client, err := ba.NewClient()
    	if err != nil {
    		log.Fatal(err)
    	}
    	a := &app{
    		client:  client,
    		agentID: ba.AgentID(os.Getenv("BLAZING_AGENTS_AGENT_ID")),
    		users:   map[string]string{os.Getenv("DEMO_USER_TOKEN"): "user-1"},
    		owners:  map[ba.SessionID]string{},
    	}
    	http.HandleFunc("POST /api/chat", a.chat)
    	log.Fatal(http.ListenAndServe(":8787", nil))
    }
    ```

    Start it with `node server.ts`, `uvicorn server:app --port 8787`, `cargo run --bin server`, or `go run ./server`.

    ## Verify the integration [#verify-the-integration]

    In a second terminal, export `DEMO_USER_TOKEN` again and ask the agent to remember something:

    ```bash
    curl -i -N http://localhost:8787/api/chat \
      -H "authorization: Bearer $DEMO_USER_TOKEN" \
      -H "content-type: application/json" \
      -d '{"message":{"id":"m1","role":"user","parts":[{"type":"text","text":"Remember the word cobalt."}]}}'
    ```

    The answer streams in as `data: {...}` lines. Among the response headers is a `location` header that ends in the new `ss_...` session ID. Send it back with a follow-up question:

    ```bash
    curl -N http://localhost:8787/api/chat \
      -H "authorization: Bearer $DEMO_USER_TOKEN" \
      -H "content-type: application/json" \
      -d '{"sessionId":"ss_...","message":{"id":"m2","role":"user","parts":[{"type":"text","text":"Which word did I ask you to remember?"}]}}'
    ```

    The agent answers "cobalt", because Blazing Agents kept the first exchange. Leave out the `authorization` header and you get `401`. Send a session ID the user does not own and you get `403`.

## What happened [#persist-and-resume-the-session]

The first request has no `sessionId`, so Blazing Agents starts a new session and returns its ID before the answer finishes streaming. Your endpoint records the owner right away, then relays the stream. Later requests send the `sessionId`, your endpoint checks the owner, and the agent sees the whole conversation. Your frontend sends only the newest message each time.

In TypeScript, `createChatRelay` does this for you. It also passes the request's abort signal along, so a user who closes the tab stops the turn. The Python, Rust, and Go endpoints do the same steps by hand with one chat call: they pass `session_id` only when the request has one, and `stream.session_id` (`stream.session_id()` in Rust, `stream.SessionID()` in Go) holds the ID either way. The Rust and Go endpoints also route a `regenerate-message` trigger to `client.regenerate()` and `client.Chat.Regenerate()`.

This relay uses a tenant-wide client. The `userId` it passes labels usage and resources, while the `owners` check protects conversations. For other resource calls, derive a [user-scoped client](/sdk/typescript/client#for-user) from your verified user ID so the API checks ownership as well.

## Production notes [#production-notes]

- Replace the demo token with your real sign-in, and the `owners` map with a database table.
- Keep the session ID even when the first turn fails or the user stops it. The conversation exists; it is empty until a turn succeeds.
- Streams must reach the browser unbuffered. The response already sets `Cache-Control: no-cache`; make sure every proxy in front of your backend passes the stream through as it arrives.
