# Set up Blazing Agents

Get an API key, install the TypeScript, Python, Rust, or Go SDK, and run a short check that proves your code can talk to Blazing Agents. You use the same project folder in the [quickstart](/getting-started/quickstart).

## Before you begin [#before-you-begin]

You need a Blazing Agents account and either Node.js 24 or later, Python 3.11 or later, Rust 1.85 or later, or Go 1.26 or later. The SDKs run on your backend, never in a browser or mobile app.

<Steps>
  <Step>
    ## Create an API key [#create-an-api-key]

    Open [API keys](https://www.blazingagents.com/app/keys) in the dashboard and create a key. Copy the full `ba_...` value right away: you see it only once.

    Put the key in your shell environment. All SDKs send it with every request.

    ```bash
    export BLAZING_AGENTS_API_KEY="ba_..."
    ```

    Your terminal now has `BLAZING_AGENTS_API_KEY` set. Open a new terminal later and you need to export it again, or load it from your usual secret store.

  </Step>
  <Step>
    ## Install the SDK [#install-the-sdk]

    Create a project folder and install the SDK for your language.

    ```bash tab="TypeScript" tab-group="sdk-language"
    mkdir blazing-quickstart && cd blazing-quickstart
    npm init -y
    npm pkg set type=module
    npm install @blazingagents/sdk ai zod
    ```

    ```bash tab="Python"
    mkdir blazing-quickstart && cd blazing-quickstart
    python3 -m venv .venv
    source .venv/bin/activate
    pip install blazing-agents
    ```

    ```bash tab="Rust"
    cargo new blazing-quickstart && cd blazing-quickstart
    cargo add blazing-agents
    cargo add tokio --features macros,rt-multi-thread
    cargo add futures-util
    ```

    ```bash tab="Go"
    mkdir blazing-quickstart && cd blazing-quickstart
    go mod init blazing-quickstart
    go get github.com/blazingagents/golang-sdk@v0.4.0
    ```

    The TypeScript SDK needs the `ai` and `zod` packages alongside it. When the install finishes, you have an empty project with the SDK ready to import.

  </Step>
  <Step>
    ## Check the connection [#check-the-connection]

    Save this file in your project folder. It creates a client and lists the agents in your tenant, which changes nothing.

    ```typescript tab="TypeScript" tab-group="sdk-language" title="check.ts"
    import { BlazingAgents } from "@blazingagents/sdk";

    const client = new BlazingAgents({
      apiKey: process.env.BLAZING_AGENTS_API_KEY!,
    });

    let page = await client.agents.list();
    const agents = [...page.data];
    while (page.nextCursor) {
      page = await client.agents.list({ cursor: page.nextCursor });
      agents.push(...page.data);
    }
    console.log(`Connected. Your tenant has ${agents.length} agents.`);
    ```

    ```python tab="Python" title="check.py"
    from blazing_agents import BlazingAgents

    client = BlazingAgents()

    page = client.agents.list()
    agents = list(page.data)
    while page.next_cursor is not None:
        page = client.agents.list(cursor=page.next_cursor)
        agents.extend(page.data)
    print(f"Connected. Your tenant has {len(agents)} agents.")
    ```

    ```rust tab="Rust" title="src/bin/check.rs"
    use blazing_agents::Client;
    use futures_util::TryStreamExt;

    #[tokio::main]
    async fn main() -> Result<(), Box<dyn std::error::Error>> {
        let client = Client::from_env()?;

        let agents: Vec<_> = client.agents().list().items().try_collect().await?;
        println!("Connected. Your tenant has {} agents.", agents.len());
        Ok(())
    }
    ```

    ```go tab="Go" title="check/main.go"
    package main

    import (
    	"context"
    	"fmt"
    	"log"

    	ba "github.com/blazingagents/golang-sdk"
    )

    func main() {
    	ctx := context.Background()
    	client, err := ba.NewClient()
    	if err != nil {
    		log.Fatal(err)
    	}

    	count := 0
    	for _, err := range client.Agents.All(ctx, ba.ListAgentsParams{}) {
    		if err != nil {
    			log.Fatal(err)
    		}
    		count++
    	}
    	fmt.Printf("Connected. Your tenant has %d agents.\n", count)
    }
    ```

    Run it with `node check.ts`, `python check.py`, `cargo run --bin check`, or `go run ./check`. The Python, Rust, and Go clients read `BLAZING_AGENTS_API_KEY` on their own; the TypeScript client takes it as `apiKey`. None needs a URL, because they all point at `https://api.blazingagents.com` by default.

    You see `Connected. Your tenant has N agents.` The count includes your [admin agent](/agents/agents#the-admin-agent), so a new tenant sees 1. If you see an authentication error instead, check that the key is exported in the same terminal and was copied in full. The [errors reference](/api-reference/protocols/errors) explains every error code.

  </Step>
</Steps>

## Keep your API key on the backend [#keep-your-api-key-on-the-backend]

<Callout type="warn" title="Keep credentials on the backend">
  Never put an API key in a browser bundle, mobile app, log, or URL. Keep it in backend configuration only.
</Callout>

One key can reach every agent in your tenant. It identifies your backend, not your users. Your app still signs users in and decides what each one may do before it calls Blazing Agents.
