# Run your first agent

Build one small program that connects your OpenRouter key, creates an agent, and streams the agent's first answer to your terminal. You add to the same file in three steps and run it after each one, so you see every piece work before you move on.

## Before you begin [#before-you-begin]

Finish [Set up Blazing Agents](/getting-started/setup) and work in the same project folder and terminal. You also need an OpenRouter API key in that terminal:

```bash
export OPENROUTER_API_KEY="sk-or-..."
```

The program is safe to run again and again. It looks up the provider and agent by name and creates them only the first time.

<Steps>
  <Step>
    ## Connect a model provider [#connect-a-model-provider]

    A provider holds the model key your agents use. Blazing Agents stores the key for you, so your program sends it only once. Create `quickstart.ts`, `quickstart.py`, `src/bin/quickstart.rs`, or `quickstart/main.go` with this code:

    ```typescript tab="TypeScript" tab-group="sdk-language" title="quickstart.ts"
    import { BlazingAgents } from "@blazingagents/sdk";

    const client = new BlazingAgents({
      apiKey: process.env.BLAZING_AGENTS_API_KEY!,
    });

    const providerName = "Quickstart OpenRouter";
    const { providers } = await client.providers.list();
    const provider =
      providers.find(({ name }) => name === providerName) ??
      (await client.providers.create({
        name: providerName,
        providerType: "openrouter",
        baseUrl: null,
        apiKey: process.env.OPENROUTER_API_KEY!,
      }));
    console.log(`Provider: ${provider.id}`);
    ```

    ```python tab="Python" title="quickstart.py"
    import os
    import sys
    import uuid

    from blazing_agents import BlazingAgents

    client = BlazingAgents()

    provider_name = "Quickstart OpenRouter"
    providers = client.providers.list().providers
    provider = next(
        (p for p in providers if p.name == provider_name), None
    ) or client.providers.create(
        name=provider_name,
        provider_type="openrouter",
        api_key=os.environ["OPENROUTER_API_KEY"],
    )
    print(f"Provider: {provider.id}")
    ```

    ```rust tab="Rust" title="src/bin/quickstart.rs"
    use blazing_agents::providers::ProviderType;
    use blazing_agents::Client;

    #[tokio::main]
    async fn main() -> Result<(), Box<dyn std::error::Error>> {
        let client = Client::from_env()?;

        let provider_name = "Quickstart OpenRouter";
        let providers = client.providers().list().await?.providers;
        let provider_id = match providers.iter().find(|p| p.name == provider_name) {
            Some(provider) => provider.id.clone(),
            None => {
                client
                    .providers()
                    .create(
                        provider_name,
                        ProviderType::OpenRouter,
                        std::env::var("OPENROUTER_API_KEY")?,
                    )
                    .await?
                    .id
            }
        };
        println!("Provider: {provider_id}");
        Ok(())
    }
    ```

    ```go tab="Go" title="quickstart/main.go"
    package main

    import (
    	"context"
    	"fmt"
    	"log"
    	"os"

    	ba "github.com/blazingagents/golang-sdk"
    )

    func main() {
    	ctx := context.Background()
    	client, err := ba.NewClient()
    	if err != nil {
    		log.Fatal(err)
    	}

    	providerName := "Quickstart OpenRouter"
    	providers, err := client.Providers.List(ctx)
    	if err != nil {
    		log.Fatal(err)
    	}
    	var providerID ba.ProviderID
    	for _, p := range providers {
    		if p.Name == providerName {
    			providerID = p.ID
    		}
    	}
    	if providerID == "" {
    		provider, err := client.Providers.Create(ctx, ba.CreateProviderParams{
    			Name:         providerName,
    			ProviderType: ba.ProviderTypeOpenRouter,
    			APIKey:       ba.NewSecret(os.Getenv("OPENROUTER_API_KEY")),
    		})
    		if err != nil {
    			log.Fatal(err)
    		}
    		providerID = provider.ID
    	}
    	fmt.Printf("Provider: %s\n", providerID)
    }
    ```

    Run it with `node quickstart.ts`, `python quickstart.py`, `cargo run --bin quickstart`, or `go run ./quickstart`. You see `Provider: prv_...`, and the same ID on every later run.

  </Step>
  <Step>
    ## Create an agent [#create-an-agent]

    An agent pairs a provider with a model. Add this to the end of the file. The Rust and Go tabs show the whole file so far.

    ```typescript tab="TypeScript" tab-group="sdk-language" title="quickstart.ts"
    const agentName = "Quickstart agent";
    let page = await client.agents.list();
    const agents = [...page.data];
    while (page.nextCursor) {
      page = await client.agents.list({ cursor: page.nextCursor });
      agents.push(...page.data);
    }
    const agent =
      agents.find(({ name }) => name === agentName) ??
      (await client.agents.create({
        name: agentName,
        providerId: provider.id,
        model: "openai/gpt-6-luna",
      }));
    console.log(`Agent: ${agent.id}`);
    ```

    ```python tab="Python" title="quickstart.py"
    agent_name = "Quickstart agent"
    page = client.agents.list()
    agents = list(page.data)
    while page.next_cursor is not None:
        page = client.agents.list(cursor=page.next_cursor)
        agents.extend(page.data)
    agent = next((a for a in agents if a.name == agent_name), None) or client.agents.create(
        name=agent_name,
        provider_id=provider.id,
        model="openai/gpt-6-luna",
    )
    print(f"Agent: {agent.id}")
    ```

    ```rust tab="Rust" title="src/bin/quickstart.rs"

    use blazing_agents::Client;
    use futures_util::TryStreamExt;

        let provider_name = "Quickstart OpenRouter";

        let provider_id = match providers.iter().find(|p| p.name == provider_name) {
            Some(provider) => provider.id.clone(),
            None => {
                client
                    .providers()
                    .create(
                        provider_name,
                        ProviderType::OpenRouter,
                        std::env::var("OPENROUTER_API_KEY")?,

                    .await?
                    .id
            }
        };
        println!("Provider: {provider_id}");

        let agent_name = "Quickstart agent";
        let agents: Vec<_> = client.agents().list().items().try_collect().await?;

                client
                    .agents()
                    .create(agent_name)
                    .model(&provider_id, "openai/gpt-6-luna")
                    .await?
                    .id
            }
        };
        println!("Agent: {agent_id}");
        Ok(())
    }
    ```

    ```go tab="Go" title="quickstart/main.go"

    	"context"
    	"fmt"

    	"os"

    	if err != nil {

    	}
    	var providerID ba.ProviderID
    	for _, p := range providers {
    		if p.Name == providerName {
    			providerID = p.ID
    		}
    	}
    	if providerID == "" {
    		provider, err := client.Providers.Create(ctx, ba.CreateProviderParams{
    			Name:         providerName,
    			ProviderType: ba.ProviderTypeOpenRouter,
    			APIKey:       ba.NewSecret(os.Getenv("OPENROUTER_API_KEY")),

    	fmt.Printf("Provider: %s\n", providerID)

    	agentName := "Quickstart agent"
    	var agentID ba.AgentID
    	for agent, err := range client.Agents.All(ctx, ba.ListAgentsParams{}) {
    		if err != nil {
    			log.Fatal(err)
    		}
    		if agent.Name == agentName {
    			agentID = agent.ID
    		}
    	}
    	if agentID == "" {
    		agent, err := client.Agents.Create(ctx, ba.CreateAgentParams{
    			Name:       agentName,
    			ProviderID: ba.Value(providerID),
    			Model:      ba.Value("openai/gpt-6-luna"),
    		})
    		if err != nil {
    			log.Fatal(err)
    		}

    	}
    	fmt.Printf("Agent: %s\n", agentID)

    ```

    Run the file again. You see the same `Provider: prv_...` line, then `Agent: ag_...`.

    Blazing Agents checks the model against your provider when you create the agent. If you get [`model_not_found`](/api-reference/protocols/errors#model_not_found), pick another ID from `client.providers.listModels({ providerId })` in TypeScript, `client.providers.list_models(provider_id=...)` in Python, `client.providers().list_models(provider_id)` in Rust, or `client.Providers.ListModels(ctx, providerID)` in Go. The first step stores your OpenRouter key without checking it, so a wrong or invalid key shows up here as [`model_validation_unavailable`](/api-reference/protocols/errors#model_validation_unavailable). Fix `OPENROUTER_API_KEY`, delete the "Quickstart OpenRouter" provider with `client.providers.delete({ providerId })` in TypeScript, `client.providers.delete(provider_id)` in Python, `client.providers().delete(provider_id)` in Rust, `client.Providers.Delete(ctx, providerID, ba.DeleteProviderParams{})` in Go, or the **Delete** action on the dashboard's [providers page](https://www.blazingagents.com/app/providers), then run the file again to recreate it with the new key.

    ## Stream the first answer [#stream-the-first-answer]

    Send the agent a message and print the answer as it arrives. Add this to the end of the file. The Rust and Go tabs show the whole file so far.

    ```typescript tab="TypeScript" tab-group="sdk-language" title="quickstart.ts"
    const result = await client.chat({
      agentId: agent.id,
      message: {
        id: crypto.randomUUID(),
        role: "user",
        parts: [{ type: "text", text: "Say hello in one short sentence." }],
      },
    });
    console.log(`Session: ${await result.sessionId}`);

    for await (const chunk of result.toStream()) {
      process.stdout.write(chunk);
    }
    // The stream is yours now: relay it to your app, parse it, or store it.
    ```

    ```python tab="Python" title="quickstart.py"
    message = {
        "id": str(uuid.uuid4()),
        "role": "user",
        "parts": [{"type": "text", "text": "Say hello in one short sentence."}],
    }
    with client.chat(agent_id=agent.id, message=message) as stream:
        print(f"Session: {stream.session_id}")
        for chunk in stream:
            sys.stdout.buffer.write(chunk)
        # The stream is yours now: relay it to your app, parse it, or store it.
    ```

    use blazing_agents::providers::ProviderType;
    use blazing_agents::Client;
    use futures_util::TryStreamExt;
    use std::io::Write;

    #[tokio::main]
    async fn main() -> Result<(), Box<dyn std::error::Error>> {
        let client = Client::from_env()?;

        let provider_name = "Quickstart OpenRouter";
        let providers = client.providers().list().await?.providers;
        let provider_id = match providers.iter().find(|p| p.name == provider_name) {
            Some(provider) => provider.id.clone(),
            None => {
                client
                    .providers()
                    .create(
                        provider_name,
                        ProviderType::OpenRouter,
                        std::env::var("OPENROUTER_API_KEY")?,
                    )
                    .await?
                    .id
            }
        };
        println!("Provider: {provider_id}");

        let agent_name = "Quickstart agent";
        let agents: Vec<_> = client.agents().list().items().try_collect().await?;
        let agent_id = match agents.iter().find(|a| a.name == agent_name) {
            Some(agent) => agent.id.clone(),
            None => {
                client
                    .agents()
                    .create(agent_name)
                    .model(&provider_id, "openai/gpt-6-luna")
                    .await?
                    .id
            }
        };
        println!("Agent: {agent_id}");

        let mut stream = client
            .chat(&agent_id, UserMessage::text("Say hello in one short sentence."))
            .await?;
        println!("Session: {}", stream.session_id());

        let mut stdout = std::io::stdout();
        while let Some(chunk) = stream.try_next().await? {
            stdout.write_all(&chunk)?;
        }
        // The stream is yours now: relay it to your app, parse it, or store it.
        Ok(())
    }

    		log.Fatal(err)
    	}

    Run the file once more. After the IDs, the raw stream prints as it arrives:

    ```text
    Provider: prv_...
    Agent: ag_...
    Session: ss_...
    data: {"type":"start",...}

    data: {"type":"text-delta","id":"...","delta":"Hello"}

    data: {"type":"text-delta","id":"...","delta":"!"}

    ...

    data: [DONE]
    ```

    These lines are AI SDK UI message events. In a web app your backend returns `result.toResponse()`, and the AI SDK `useChat` hook renders them as chat messages. Each run starts a new session, so you see a new `ss_...` ID every time.

## What happened [#what-happened]

`client.chat()` without a `sessionId` starts a new session, a conversation that Blazing Agents keeps for you. You get the session ID before the answer finishes streaming, so you can save it right away. Pass it back as `sessionId` (`session_id` in Python, `.session()` on the chat call in Rust, `ChatParams.SessionID` in Go) on the next call and the agent sees the whole conversation so far.

The answer arrives as a stream of server-sent events in the AI SDK UI message format, and the program prints them untouched. The stream is yours: relay it to your app, parse it, or store it. In a web app, return `result.toResponse()` from your backend and the AI SDK `useChat` hook renders it for you.
