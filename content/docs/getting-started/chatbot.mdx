# Build a chatbot

Put a chat UI in front of your agent with the `useBlazingAgentsChat` React hook. Blazing Agents keeps the history, and the hook keeps the session ID, shows the stored conversation again after a reload, and sends a message typed during a reply into the running turn. In Vue, Angular, or plain JavaScript, use [`BlazingAgentsChat`](/sdk/typescript/blazing-agents-chat) instead, which does the same without React.

## Before you begin [#before-you-begin]

Finish [Connect Blazing Agents to your app](/getting-started/connect-your-app). This page talks to that `/api/chat` endpoint, which works the same whether you wrote it in TypeScript, Python, Rust, or Go.

You need a React app served from the same origin as the endpoint, for example through your dev server's proxy. Install the SDK with React:

```bash
npm install @blazingagents/sdk ai zod react
```

## Add the chat component [#sdk-native-example]

`useBlazingAgentsChat` posts to `/api/chat` with your user's token and returns the messages to render and a `send()` function.

```tsx title="Chat.tsx"
import { useBlazingAgentsChat } from "@blazingagents/sdk/react";
import { useState } from "react";

export function Chat({ token }: { token: string }) {
  const [input, setInput] = useState("");
  const chat = useBlazingAgentsChat({
    headers: { authorization: `Bearer ${token}` },
  });

  return (
    <main>
      {chat.messages.map((message) => (
        <p key={message.id}>
          <strong>{message.role}:</strong>{" "}
          {message.parts.map((part) => (part.type === "text" ? part.text : ""))}
        </p>
      ))}
      <form
        onSubmit={(event) => {
          event.preventDefault();
          void chat.send(input);
          setInput("");
        }}
      >
        <input value={input} onChange={(event) => setInput(event.target.value)} />
        <button type="submit">Send</button>
      </form>
    </main>
  );
}
```

Render `<Chat token={...} />` with your user's sign-in token. With the demo endpoint from the previous page, that is the value of `DEMO_USER_TOKEN`. Send a message and the answer streams in. Send another while it streams, and the agent reads it at its next step and answers in the same reply. Reload the page, and the conversation comes back and continues, because the hook keeps the session ID in `localStorage`.

## What to add next [#chatbot-faq]

The component above is the smallest chat that works. Add the pieces your product needs, by hand or by asking your coding agent. The [React chat hook reference](/sdk/typescript/use-blazing-agents-chat) describes each member.

- **Stop.** Show a Stop button while `chat.status` is `"running"` and call `chat.stop()`. The turn is cancelled, and the hook shows the stored conversation again. Stop cannot undo a tool call that already ran.
- **Put a failed message back.** `chat.send()` resolves `false` when an error or Stop rolled the message back. Put its text back in the input so the user can edit it and send it again. Each send is a new attempt, so a tool that ran during the failed one can run again.
- **Show errors.** Render `chat.error`. It is a `BlazingAgentsError` with the endpoint's `status` and `code`, and the next `send()` clears it.
- **Regenerate.** Call `chat.regenerate()` to replace the last saved answer, and enable the button only while `chat.canRegenerate` is `true`. If the new answer fails or is stopped, the old one stays.
- **New conversation.** Call `chat.newSession()`. The next message starts a new session.
- **Pending messages.** `chat.pendingIds` holds the IDs of sent messages that are not stored yet, so you can style them as sending.
- **Images.** Pass files with the text: `chat.send({ text, files })`, where each file is an AI SDK file part with an image media type and a `data:` URL. See [send an image](/agents/output/generation-and-streaming#send-an-image).
- **Tool approvals.** When an agent needs a person to allow a tool call, the reply ends with a tool part in the `approval-requested` state. Render buttons that call `chat.addToolApprovalResponse({ id: part.approval.id, approved })`, and the rest of the turn streams in. The endpoint from the previous page resumes the turn for you in every language. See [render the resumed answer](/agents/tools/tool-approvals#render-the-resumed-answer).
