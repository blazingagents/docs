# Getting Started

Install the backend SDK, create an Agent, complete one streamed Turn, and connect it safely to an application. This path keeps your Blazing Agents credential behind your authenticated backend from the start.

## The shortest path to a working Agent [#the-shortest-path-to-a-working-agent]

<Steps>
  <Step>
    ### [Set up Blazing Agents](/getting-started/setup)

    Finish with an authenticated SDK client that can list your tenant's Agents.

  </Step>
  <Step>
    ### [Run your first Agent](/getting-started/quickstart)

    Finish with an `ag_...` Agent ID, an `ss_...` Session ID, and a streamed answer.

  </Step>
  <Step>
    ### [Connect Blazing Agents to your app](/getting-started/connect-your-app)

    Finish with an authenticated backend endpoint that relays the stream and safely resumes a Session.

  </Step>
  <Step>
    ### [Choose what to build next](/getting-started/next-steps)

    Finish by selecting the Agent, Platform, Automation, CLI, or SDK section that matches your product outcome.

  </Step>
</Steps>

## What you will build [#what-you-will-build]

**Browser or mobile app → authenticated tenant backend → Blazing Agents**

The API key remains on the backend. Your backend authenticates each end-user, authorizes access to your application's resources, selects the Agent, and calls Blazing Agents.
