# Choose what to build next

Your agent can chat with your users. Pick what you want it to do next and start on that page. Each one works with the agent, endpoint, and chat UI you already have.

## Common next steps [#common-next-steps]

| I want my agent to... | Start here |
| --- | --- |
| Work with files and run commands | [Workspaces](/agents/workspaces) |
| Follow reusable instructions only when they apply | [Skills](/agents/skills) |
| Call my APIs or other services | [MCP tools](/agents/tools/mcp-tools) or [built-in tools](/agents/tools/built-in-tools) |
| Ask a person before a risky tool call | [Tool approvals](/agents/tools/tool-approvals) |
| Remember facts across conversations | [Memory](/agents/memory) |
| Return typed JSON instead of prose | [Structured output](/agents/output/structured-output) |
| Run with nobody watching, once or on a schedule | [Tasks](/automation/tasks) and [schedules](/automation/schedules) |
| Answer in Slack or Telegram | [Chat integrations](/platform/chat-integrations) |
| Track token usage per user, or bill users for it | [Usage and quotas](/platform/usage-and-quotas) and [monetization](/platform/monetization) |
| Run from my terminal or a CI job | [CLI](/cli) |
