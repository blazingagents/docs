# Python SDK

Call Blazing Agents from Python with typed responses, sync and async clients, lazy pagination, and streaming. Install `blazing-agents` from PyPI and import it as `blazing_agents`. It supports Python 3.11 and newer.

<Callout type="warn" title="Server-side only">
  A tenant API key can reach everything in your tenant. Keep it in backend code and never ship it to a browser or mobile app.
</Callout>

## Install [#install]

```bash
pip install blazing-agents
```

## Create a client [#create-a-client]

Set `BLAZING_AGENTS_API_KEY` in your environment, or pass `api_key` to the constructor. The client talks to `https://api.blazingagents.com` by default.

```python
from blazing_agents import BlazingAgents

with BlazingAgents() as client:
    tenant = client.tenant.get()
    print(tenant.name)
```

For async code, use `AsyncBlazingAgents`. It has the same method names; you `await` them, and use `async with` and `async for` where the sync client uses `with` and `for`. There is no `achat()` or other `a`-prefixed alias.

```python
from blazing_agents import AsyncBlazingAgents

async def show_tenant() -> None:
    async with AsyncBlazingAgents() as client:
        tenant = await client.tenant.get()
        print(tenant.name)
```

## Conventions [#conventions]

- Arguments use snake case. Some methods take leading arguments by position, such as `agent_id` in `client.agents.get(agent_id)`. Others take every argument by keyword, such as `client.workspaces.get(workspace_id=...)`. Each method's signature shows which, and every later argument is keyword-only.
- Omitting an argument sends nothing, so the server keeps its default or current value. Passing `None` sends JSON `null`, which clears a nullable field.
- Responses are Pydantic v2 models with snake-case fields. Unknown server fields stay in `model_extra`, so a newer API does not break your code.
- `response_meta(model)` returns the status, server request ID, and headers of the response behind a model. Keep the request ID when you contact support. See [request IDs](/sdk/python/client#response-observation-and-request-ids).
