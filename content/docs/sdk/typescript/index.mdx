# TypeScript SDK

`@blazingagents/sdk` is the typed Node.js client for the Blazing Agents `/v1`
API. Use its resource methods to manage configuration and data, and its
generation helpers to stream Agent output.

<Callout type="warn" title="Server-side only">
  A Tenant API key can access every resource in its Tenant. Never expose it to
  browser, mobile, or End-user code. Call the SDK from your authenticated backend.
</Callout>

## Install [#install]

The SDK requires Node.js 24 or newer and `ai` 7.0.32 as a peer dependency.

```bash
npm install @blazingagents/sdk ai@7.0.84
```

## Initialize the client [#initialize-the-client]

```typescript
import { BlazingAgents } from "@blazingagents/sdk";

export const client = new BlazingAgents({
  apiKey: process.env.BLAZING_AGENTS_API_KEY!,
});
```

The client uses `http://localhost:8787` by default. Set `baseUrl` for another
deployment or provide a custom `fetch` implementation. See [Client
configuration](/sdk/typescript/client).

## Common workflow [#common-workflow]

Create an Agent, start a Session with `chat()`, retain its ID, and consume the
decoded UI message stream:

```typescript
import { BlazingAgents, type UIMessage } from "@blazingagents/sdk";

const client = new BlazingAgents({
  apiKey: process.env.BLAZING_AGENTS_API_KEY!,
});

const agent = await client.agents.create({ name: "Support Agent" });
const message = {
  id: crypto.randomUUID(),
  role: "user",
  parts: [{ type: "text", text: "How can I reset my password?" }],
} satisfies UIMessage;

const result = await client.chat({ agentId: agent.id, message });
const sessionId = await result.sessionId;

await result.toResponse().text();

console.log(`\nSession: ${sessionId}`);
```

Pass `sessionId` to a later `chat()` call to continue the same Session. Use
`completion()` for stateless text or `object()` for stateless structured output.
See the root [generation methods](/sdk/typescript/client#generation-methods) for all three result
interfaces and streaming patterns.

## Errors and response validation [#errors-and-response-validation]

Request, transport, and stream failures throw `BlazingAgentsError`. Branch on
its stable `code`; optional fields include `status`, `requestId`, `details`, and
the underlying `cause`. Successful JSON resource responses are validated against
the shared Zod contracts. See [Client errors](/sdk/typescript/client#errors)
and [protocol errors](/api-reference/protocols/errors).
