# SDK

Manage agents, run turns, and read results from your backend code with a typed client. Both SDKs cover the full API, check responses for you, and raise a `BlazingAgentsError` when a request fails.

```typescript tab="TypeScript" tab-group="sdk-language"
import { BlazingAgents } from "@blazingagents/sdk";

const client = new BlazingAgents({
  apiKey: process.env.BLAZING_AGENTS_API_KEY!,
});

const { agents } = await client.agents.list();
```

```python tab="Python"
from blazing_agents import BlazingAgents

client = BlazingAgents()

agents = client.agents.list().agents
```

Keep your API key on the server. It can reach every resource in your tenant, so never ship it to a browser or mobile app.
